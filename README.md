# FFT-Option-Pricing-Carr-Madan-
Option Pricing using Fast Fourier Transform
# Definitions
1.Options:An option is a financial derivative whose value depends on an underlying asset.

2.European Call Option:A European call gives the holder the right, but not the obligation, to buy an asset at maturity $T$ for strike price $K$.
  
  Payoff: $``C_T = \max(S_T-K,0)``$

  3.Put Option: A European put provides the right to sell the asset.
  Payoff: $``P_T=\max(K-S_T,0)``$
